# Place data sources

- `counties.json` — county-level boundaries from AreaCity-JsSpider-StatsGov, release 2025.251231.260403, file `ok_geo.csv` (MIT License, © 2019 xiangyuecn). https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov
  Converted from GCJ-02 to WGS-84, simplified to 0.01° (about 1 km), coordinates rounded to 0.001°. English names are the dataset's pinyin field.
- `towns.json` — populated places with population ≥ 500 in China from GeoNames `cities500`, as packaged in geonamescache 3.0.2. GeoNames data is licensed CC BY 4.0. https://www.geonames.org/
  Chinese names are taken from the GeoNames alternate names.
